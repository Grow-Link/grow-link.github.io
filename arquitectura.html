GrowLink

Arquitectura de la plataforma

3 microservicios 1 front con nginx 3 bases PostgreSQL 1 broker RabbitMQ 7 réplicas de servicios (Compose)
conexión entre componentestramo activo del flujo elegido Las pilas de cajas son réplicas del servicio

Cada decisión responde a un problema concreto que apareció al correr varias réplicas de cada servicio. Abre cada tarjeta para ver cómo está resuelto.

Una rama de cada repositorio se despliega sola a su propio ambiente. El camino es el mismo para los tres servicios y para el front, solo cambia cómo se construye lo que se sube.

Variables de cada Web App

VariableDónde y para qué
GROWLINK_JWT_SECRETEl mismo valor en los tres servicios, para validar el token.
GROWLINK_INTERNAL_KEYLa misma en usuarios y trivia, para sus llamadas internas.
PORT y WEBSITES_PORTPuerto del servicio: 8080, 8086 y 8085. En el front solo WEBSITES_PORT=80.
CLAUDE_API_KEYEn cursos, para el roadmap con IA. Sin ella usa el modo de respaldo.
USUARIOS_URL, CURSOS_URL, TRIVIA_URLEn el front, con la dirección de cada servicio. Más DNS_RESOLVER=168.63.129.16.
TRIVIA_BROKER_RELAY_*En trivia, apuntan al RabbitMQ compartido.
